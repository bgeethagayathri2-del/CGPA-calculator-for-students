# CGPA Calculator for Students

A free web app that helps students calculate their SGPA and CGPA, and plan the SGPA they need next semester to reach a target CGPA.

**Live app:**  https://cgpa-calculator-for-students-h6lxpy24wssyhytp8gtt2m.streamlit.app/

## Features
- SGPA for each semester, from credits and grades
- Overall CGPA across up to 8 semesters
- Target planner: the SGPA needed next semester to reach a goal CGPA
- Grade points are easy to change in `app.py` to match any college's scheme

## Who it is for
Students who want a quick, simple way to check and plan their grades.

## Run it yourself
```
pip install -r requirements.txt
streamlit run app.py
```

## Limitations
This is an unofficial tool. Grading schemes differ between colleges, so check the grade points in `app.py` and your college's official rules.
